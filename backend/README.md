# Wedyora API

Express + JWT + Socket.io backend for the marketplace frontend.

```bash
cp .env.example .env
npm install
npm run dev
```

- Health: `GET /api/health`
- Docs: `GET /api/docs`
- Smoke: `npm run smoke`

Demo mode seeds `customer@wedyora.test` / `vendor@wedyora.test` with password `Password123!`.
